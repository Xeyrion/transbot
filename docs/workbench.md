# 统一启动入口

日常在控制机桌面双击 **Transbot 数据工作台**，或在应用菜单中搜索 Transbot。

首页两个入口：

- **录制控制**：打开采集、停止、状态与回传窗口。
- **数据阅读**：打开会话列表，进入文件夹后分析、回放。

它们默认共用控制机数据根目录 `~/robot_research/bagtools/bags`。工作台首页显示该路径，并可打开对应文件夹。机器人采集仍在机器人本地目录进行，回传后才出现在控制机的阅读器中。

工作台本身不会连接机器人或开始录制；点击“录制控制”才打开已有控制台。关闭工作台不会结束其他工具窗口或机器人录制，停止录制请使用录制控制台的“停止”。同一工作台不会重复启动仍在运行的工具窗口。

## 语义结果回放

在「数据阅读」主窗口选中会话或分卷，点击「生成语义地图」。回放窗口也有同一入口。「建图 / 重新建图」可独立生成墙体和障碍物底图。语义生成使用已有底图及轨迹，没有底图时使用记录的里程计坐标。选择 YOLO26s（检测框中心取深度）或 YOLO26s 分割（原 B1，分割掩膜内取深度）。两项操作各自启动。语义生成处理同次录制的分卷，完成后切到回放结果并保存 PNG。

这里可选的是墙体和障碍物的栅格图像。三维物品定位仍需要有效深度、相机内外参和机器人位姿；单帧物品定位也需要这些数据。没有底图时依靠 odom 位姿，存在累计漂移。数据缺失或位姿过期的采样帧不会进入三维融合，检测区域没有可靠深度时只保留二维识别与拒绝原因。

「语义回放」默认列出当前录制两种常用方案的最新结果。「更多」可显示历史实验、手动加载运行目录、重新导出最终地图或打开结果目录。「视图」集中管理识别框、地图物品点、类别筛选、布局、缩放和跟随。

RGB 显示类别、置信度、有效深度和对应地图候选编号。框的颜色：绿为已融合到候选，蓝为有深度但尚未满足融合条件，橙为深度投影被拒绝，灰为未纳入当前融合类别。「显示其它识别类别」用灰框显示当前帧里被地图类别筛选排除的检测，例如背包或瓶子。开启后会同时开启识别框，状态栏会显示当前帧的额外框数量。这个选项只影响回放叠加层。地图蓝点为其他候选，绿点为当前帧关联候选；编号与 RGB 中 `#编号` 一致。“识别框”“物品点”可独立开关，三合一导出保留当前叠加。

显示的是模型推理框，不是人工训练标注。语义回放使用检测时保存的采样 RGB 和投影到 RGB 像素网格的深度；当前演示约每秒一组，不是每个原始视频帧都检测过。时间信息显示实际采样帧与采样时刻；遇到距离采样超过 0.65 秒的位置显示无语义帧，不把旧框套在新图片上。深度中的紫色表示无效测距。

启用「更多 → 显示全部历史结果」后，算法对照版本会用 A0–C2 等短名称显示在下拉框里。B0 是分割模型的中心取深度对照，YOLO26s 分割（原 B1）使用相同图片、相同检测和掩膜的表面取深度方案；C0–C2 提高到约 3Hz，再对比融合条件。勾选“识别框”也会显示该模型保存的半透明实例掩膜。导出文件按运行名区分，避免相同模型、相同时刻的不同算法互相覆盖。

语义模式加载该运行记录的地图和轨迹，并核验来源及已记录的几何 SHA-256；切回“原始数据”恢复该包当前地图/里程计视图。这里不会替换当前地图。地图点是全会话完成融合后的候选，包含当前时刻之后的观测，表示可见表面估计位置；不能当成在线识别结果、真实物体计数或物体中心真值。

## 调整大小与最终地图

阅读器左右、右侧上下的分隔栏均可拖动；RGB 和深度图按实际面板大小等比例缩放，也允许放大小图。“画面优先”“地图优先”“均衡布局”可快速切换比例。地图使用整个画布，支持滚轮/加减号缩放、左键拖动平移；“全图”显示完整会话范围，“跟随机器人”恢复跟随。“放大地图”打开独立、可最大化的实时地图窗口。

「地图图库」直接打开当前录制的 PNG 目录。「更多 → 最终地图」可重新导出，「更多 → 结果目录」打开当前语义运行及其日志相关资料。默认目录结构如下。

```text
<录制文件夹>/
  *.bag
  maps/<bag 主干>/                  底图和轨迹
  semantic/<bag 主干>/
    gallery/                        最终 PNG
    logs/                           界面生成日志
    <运行名>/                       检测结果、样本及底图快照
```

模型权重统一放在项目的 `models/`，常用方案在 `semantic_presets.py` 注册。批量重新导出可运行 `python3 semantic/export_maps.py --bag <bag>`。更新界面后请重新打开「数据阅读」。

## 命令行兼容

```bash
~/robot_research/bagtools/run.sh                  # 工作台首页
~/robot_research/bagtools/run.sh --record         # 直接打开录制控制
~/robot_research/bagtools/run.sh --review         # 直接打开阅读器
~/robot_research/bagtools/run.sh /path/to/bags     # 兼容原来的目录参数
```

`recording/run.sh`保留兼容，日常不再需要进入该目录寻找入口。

可选环境变量 `BAGTOOLS_DATA_DIR`（其次 `LOCAL_DIR`）覆盖共用的控制机数据目录；默认无需设置。

桌面快捷方式由 `install_workbench.sh` 安装，执行路径与当前安装目录绑定。移动代码目录后重新运行安装器即可。工具启动日志位于 `~/.cache/transbot_bagtools/launcher/`。
