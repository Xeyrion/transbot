# 相机安装外参

用户已确认：仍使用之前标定的同一台机器人，相机支架没有拆装或调整。因此无需因换车重做全部标定。

历史实验记录过 pitch −9.65°、roll +6.23°，深度与雷达最近邻残差从 6.2 cm 降至 3.5 cm。yaw 和前后/左右位移当时未可靠解出；残差不是独立位置真值误差。该历史结果未直接拼入本轮配置；不能把默认安装尺寸当作已验证标定。

先读取当前 TF/URDF 并确认车体与相机参考点，再测量缺失平移、复核高度。使用深度相机和二维雷达都能看到的两个竖直面，机器人在平整地面静止录制；换几个位置分别采集，支架保持不动。

`semantic/calibrate_camera.py` 使用静止证据、实际深度内参和光心变换生成候选。优先提供量测的 yaw、xy、高度；`--solve-yaw-xy` 是显式实验模式，不能把未独立验证的自动配对当作真值。

候选配置通过独立位置的墙面与目标检查后，再统一供录制和语义投影使用。配置格式由 `calibration_schema.py` 管理，记录 id、变换与 estimated 状态。二维雷达建图本身不依赖相机安装外参。

本轮同车、支架未动的墙面/右板观测已生成 `wallboard_20261116_multi_pose_trial`。
第一处求解后冻结参数，在前移约 30 cm 和俯视逆时针转向后的数据上验证；
前移后墙面、右板 P95 点到面偏差分别为 9.9、15.1 mm，转向后墙面为 14.6 mm。
这些是平面对齐检查，不是独立位姿真值精度；高度来自约 18.5 cm 人工量测，仍标记 `estimated=true`。
原始证据保存在 `results/calibration_review/`，旧候选不改写。

当前单车配置统一放在 `recording/calibration.json`，随录制脚本部署到机器人脚本目录。
`record_full.sh` 与 `preflight.sh` 默认读取它；指定 `BAGTOOLS_CALIBRATION` 可显式选择另一份配置。
`record_sources.launch` 负责唯一的相机安装 TF 发布，不修改厂商 launch 文件。
自检比较实际收到的安装 TF 与配置（1 mm / 0.1° 数值一致性容差，并非标定精度），
同时检查直接发布源；数值不符、缺失或多源时检查失败。
`--fix` 只重启已知的录制数据源，切换到统一配置；若仍有其他相机 TF 发布者，不叠加发布。
`--no-launch` 只检查，不自动切换。每次完整录制会在会话目录保存 `calibration.json`，
包内 `/tf_static` 同时保留实际使用的变换。部署版本校验包含配置和 launch 文件。

离线语义投影优先使用新包实际记录的 TF。旧包若需使用这份配置，应显式传入标定，
并按离线工具要求选择替换已记录外参及允许估计外参，不能只凭旁边存在一个 JSON 就当作已生效。
