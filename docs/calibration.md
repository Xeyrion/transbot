# 相机安装外参

用户已确认：仍使用之前标定的同一台机器人，相机支架没有拆装或调整。因此无需因换车重做全部标定。

历史实验记录过 pitch −9.65°、roll +6.23°，深度与雷达最近邻残差从 6.2 cm 降至 3.5 cm。yaw 和前后/左右位移当时未可靠解出；残差不是独立位置真值误差。完整旧参数仍需找回，不能把默认安装尺寸拼成已验证标定。

先读取当前 TF/URDF 并确认车体与相机参考点，再测量缺失平移、复核高度。使用深度相机和二维雷达都能看到的两个竖直面，机器人在平整地面静止录制；换几个位置分别采集，支架保持不动。

`semantic/calibrate_camera.py` 使用静止证据、实际深度内参和光心变换生成候选。优先提供量测的 yaw、xy、高度；`--solve-yaw-xy` 是显式实验模式，不能把未独立验证的自动配对当作真值。

候选配置通过独立位置的墙面与目标检查后，再统一供录制和语义投影使用。配置格式由 `calibration_schema.py` 管理，记录 id、变换与 estimated 状态。二维雷达建图本身不依赖相机安装外参。
