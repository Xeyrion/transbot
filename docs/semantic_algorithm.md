# 当前语义地图算法

当前实现是离线物体级语义地图研究基线。地图是几何背景，检测模型提供类别，深度提供光心系三维观测，TF 提供世界位姿；雷达没有必要和相机同频更新，但每一路都必须使用自己的采集时间。

```text
同一会话的原始分卷
  → 检查时间连续性/地图关联/标定
  → RGB header 最近邻配深度（默认 ≤33 ms，逆序拒绝）
  → 深度按源相机 K、D 反投影
  → T_color(t_rgb)^-1 × T_depth(t_depth) 跨视角、跨时刻投影
  → 彩色网格 z-buffer（同一像素取最近表面）
  → YOLO 输出二维框/类别，可选实例掩膜
  → 中心 ROI 基线或连通深度表面实验，保留具体拒绝原因
  → 彩色 K、D 反投影，乘 T_world_color(t_rgb)
  → 同类别三维 complete-link、每帧一票
  → objects.json + 保留来源的观测 + 地图背景渲染
```

## 时间和坐标

采集时间来自消息 Header；bag 记录时间仅用于定位消息和选择经审查的时间段，不能替代采集时间。动态 TF 有时效约束，常规边最多 0.5 秒，map→odom 校正最多 10 秒；静态边不按年龄过期。动态普通边做平移插值和最短弧四元数插值，map 校正使用最近过去值。

同一动态边、同一时间戳的多次发布先做有界去重：整组平移差不超过 1 mm、转角差不超过 0.1° 时，保留载入顺序最后一项。原始分卷按录制顺序载入，已关联的重建轨迹随后载入；重复修正及差异写入 geometry.duplicate_tf。超过任一界限仍报冲突，静态变换保持原检查。这是解析重复小修正的容差，不是标定精度，也不修改 bag、时间戳或修复时间回退。

重投影输出的深度与彩色像素、K、D、光心 frame 和世界变换一致。保留未配准彩色图时，投影也要把镜头畸变应用到目标像素；将目标像素变回射线时则反解畸变。迭代反解不收敛、编码不支持或数据不足时拒绝该观测。

没有 map→odom 时输出 world_frame=odom，不把里程计坐标偷偷画进 map 底图。重建地图的 association 指定轨迹、来源及时间范围，不能把不同会话中同名 map 当成共同原点。

## 单帧物体观测

默认 `center` 基线：检测框中部取一半宽高的 ROI；有效深度须在 0.2–8 m，至少 10 个有效像素，且有效比例至少 25%。

取深度中位数 z，MAD 不能超过 max(0.1 m,0.1z)。主表面要求在 max(0.03 m,3×1.4826×MAD) 范围内有至少 70% 有效深度支持。随后使用该表面有效像素的代表位置生成射线，经 K、D 和 TF 得到世界位置。

这里得到的是“框内可见表面位置”，不是完整三维物体的几何中心。桌椅遮挡、背景占据 ROI、多层表面仍可能造成漏用或错误表面选择。

可选 `surface` 在同一个中心 ROI 中寻找连通深度表面；`mask-surface` 使用分割模型输出的原生 RGB 网格实例掩膜作为区域。两者仍要求至少 10 个有效像素和 25% 有效比例；按 8 cm 深度直方图寻找候选，取半宽 max(8 cm,4% 深度) 内的四连通支持区域，至少覆盖 20% 有效区域。竞争表面支持数达到最佳表面的 80% 时拒绝歧义。表面法选择实际有测量值的代表像素与深度，不选掩膜空洞或插补缺失测量。它仍可能选中错误背景，不能单凭接受率提高证明更准确。

掩膜以 PNG 保存在对应运行中，缓存检测绑定 RGB SHA-256、记录时间及掩膜 SHA-256；切换投影法不重复推理。缓存没有覆盖更低置信度阈值时拒绝该请求。运行保留样本、模型、地图、源码和缓存来源；回放以半透明掩膜显示模型区域，橙色标签细分有效深度少、距离混杂、支持不足、竞争表面等原因。

sigma_m=max(0.02 m,1.4826×MAD) 仅描述深度离散度，不包含外参、机器人位姿或 SLAM 误差，不是经过标定的完整位置协方差。原始二维检测与拒绝状态保留，便于单独评价检测器。

## 多帧融合

同类别观测按确定顺序处理，用三维点对距离限制形成 complete-link 分组，默认最大点对距离 0.6 m。它防止单链把一串相邻物体无限串起来，也按高度区分重叠的 xy 点。

每帧每簇最多一票，重复检测选择分数最高的一条。至少 3 个不同帧支持才生成物体。位置采用 score/sigma² 的启发式加权，保留散布、完整观测帧与来源、运行内 object_id。这个分数不是贝叶斯物体存在概率。

实验可另设最短时间跨度和视角支持：本轮 C1/C2 要求至少 1 秒，且相机平移至少 0.15 m 或光轴夹角至少 8°。提高抽帧频率不能单凭短时间重复帧绕过此条件。被过滤的组及原因保留在 `rejected_groups`。

`--association instance` 是可选的实例约束实验：同帧不同观测的框 IoU 小于 0.5 时不能合并；椅子用水平 `radius`、垂直 0.8 m 的椭球度量，允许椅背和椅座的可见表面高度变化。本轮 C2 的水平半径 0.45 m。它是类别与共视关系启发式，仍不是完整图像跟踪或已验证的实例匹配，其他物体仍采用原三维距离。

动态类别默认排除在静态地图之外，检测记录仍保留。该实现不包含跨帧跟踪、长期物体 ID、动态轨迹、回环后全局历史优化，也不把独立会话直接融合成同一地图。若研究目标需要这些能力，属于后续算法研究，而不是现有工程错误的修复。

## 后续评价应分开进行

先用固定检测框检查投影与深度，再用固定三维观测检查实例误合并/误拆分，最后用按会话隔离的标注集比较模型。必须有独立量测的参考；能画出地图、通过构造测试、靠近某段墙或使用了小 YOLO，都不能单独证明定位准确。

## 当前对照入口

`semantic/compare_runs.py <已完成基线目录> --suite <新实验名>` 生成 A0/A1、B0/B1/B2、C0/C1/C2，拒绝覆盖已有目录，样本采用只读约定的硬链接共享。`semantic/review_experiments.py <comparison.json>` 输出同图深度对比、共用坐标范围的地图对比及输入一致性检查。

控制机本轮结果为 `results/semantic_comparisons/depth_20261117_v2/`。8 个主包版本可在阅读器的“语义回放”直接选择；另有短包 D0/D1，使用独立里程计坐标，不能与主包地图叠加。所有实验仍待人工核验重复点、误合并及位置；没有自动选出所谓最佳算法，也未替换原 demo。
