# 日常工作流

1. 从 `run.sh` 或桌面 Transbot 数据工作台进入；英文版本使用 `run_en.sh`。
2. 在“录制控制”中开始、停止和回传。机器人须先连接并部署匹配的录制脚本包。
3. 在“数据阅读”中选择会话文件夹，分析分卷或打开查看器。
4. 点击“建图 / 重新建图”。已有当前地图时确认替换；后台可看状态与日志，也可以取消。
5. 完成后重新打开分卷，即使用最新地图和最新轨迹。旧图集中归档，不自动回退。
6. 需要物品标记时运行 `semantic/run_semantic.sh`，输出到 `results/semantic/`。

同次录制的分卷作为一个整体处理，不把一个文件夹里的不同录制混在一起。若存在时间异常，建图会使用最长连续片段并显示范围；查看器不会把范围外数据套到新地图坐标。

下一轮采集先录短的静止/移动试验，正常停止并核对时间、TF、雷达和 RGB-D；通过后再录正式会话。录制前核对系统时间，录制过程中不要手动跳时。数据质量与地图覆盖看实际结果，不以旧底图或仅有 complete 标志代替检查。

相机仍是同一台车、支架未变化。本轮墙面与板材候选经独立位置检查，统一配置在 `recording/calibration.json`；录前核对实际 TF，录制会话保存配置副本，详见 [calibration.md](calibration.md)。裂缝图片准备和标注见 [LABELING.md](../semantic/LABELING.md)。
