## 2026-10-09 首次连通

```bash
source ../../console/env.sh
# 机器人(master): 192.168.1.11, ROS_IP(本机): 192.168.1.211
rostopic echo /voltage -n 1   # Voltage: 11.5
rosnode list | wc -l          # 20
rostopic hz /scan             # 7.35 Hz
rostopic echo /scan -n 1      # range_min 0.15, range_max 12.0, frame laser
rostopic echo /odom -n 1      # odom -> base_footprint
rosservice call /CurrentAngle # 167 / 140 / 158
rostopic list | grep camera   # 无 /camera/*，只有 /image 且无数据
rostopic hz /image            # no new messages
```

结论：底盘/雷达/odom/臂全活，相机链路是断的。Astra 需手动起
`roslaunch transbot_nav transbot_bringup.launch`（含 astrapro.launch）后才有深度。
