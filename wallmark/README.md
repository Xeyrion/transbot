## 核心矛盾

- Astra 深度相机量程 0.6~8m，臂展 34cm → 不可能在“能测距”的距离直接画。
- 解法只能是两段式：远处测（0.8~1m）→ 盲开过去贴墙画
  （standoff ≈40cm，j7 轴离墙约 27cm）。

## 用法

```bash
cd wallmark

# 1. 离线自检（不连机器人）
python3 scripts/test_kin.py

# 2. 真机画线（先 source 控制台环境）
source ../console/env.sh
python2 scripts/draw_ready.py --dist 40 --z 8 --direction down --length 1.0 --dry
# 去掉 --dry 才会真的动臂；先确认机器人周围安全
```

`draw_ready.py` 的 `--dist` 是 base_link 到画板的距离，`--z` 是相对 j7 轴的高度。
脚本会先用激光核对距离，再逆解、慢速摆位、人工确认接触后画线。

## 两项前提约束

1. **机械臂无力反馈** —— 只能靠弹簧笔套 + 过压 5mm + 视觉确认画上了，不能靠力闭环。
2. **2D 雷达不够** —— 雷达只管底盘摆平行 + 粗距离，笔尖高度的距离必须靠深度（或近距离替代方案）。
