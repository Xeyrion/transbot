# 真机几何标定（以人工实测为准）

> 结论：**真机不是按厂家 URDF 安装的。控制真机时只用本文件的实测值，
> 不用 URDF 的 8.285 / 18.341。** URDF 只描述 Gazebo 里的简化模型，
> 现在也已改成下面的实测长度。
>
> 这些值最初记在
> `../wallmark/docs/05-关节标定.md`。
> 当时因为和 URDF 对不上被标成“存疑”，但用户确认以实测为准，所以现在
> 把它固定到本项目，作为唯一口径。

## 1. 实测值（2026-10-09，钢卷尺，±0.5 cm）

| 量 | 实测值 | 说明 |
|---|---|---|
| `L1` | **10.0 cm** | j7 轴心 → j8 轴心 |
| `L2` | **24.0 cm** | j8 轴心 → 笔尖，j9≈159 夹笔状态 |
| `J7_AXIS_X` | **12.9 cm** | j7 轴心相对 base_link 的 x |
| `J7_AXIS_Z` | **8.0 cm** | j7 轴心离地/台面高度 |
| 两节共线 | **j8 ≈ 180°** | `rel=j8−180=0`；与 j7 无关 |

`L2 = 24.0` 的构成：URDF 的 j8 轴 → 夹爪末端 `17.714 cm`，加上笔伸出
夹爪的 `6.286 cm`。**换笔、把笔往夹爪里多插/少插，只改后一项**，需要
重新量 `L2`；`L1` 和前 17.714 不变。

j9 夹笔实测：**158~160° 夹紧**，角度越大越紧。当前面板不发送 j9；如果
真机 j9 不是 159 附近，笔可能在夹爪里滑动，`L2` 会变，画线前要复测。

## 2. 厂家 URDF 与实测的冲突（不要用 URDF 控制真机）

| 量 | 实测 | 厂家 URDF | 差 |
|---|---|---|---|
| `L1`（j7 轴 → j8 轴） | **10.0 cm** | 8.285 cm | **1.72 cm** |
| j7 轴相对 base_link 的 x | **12.9 cm** | 18.341 cm | **5.44 cm** |
| j7 轴相对 base_link 的 z | 0（base_link 高 8.0） | −0.164 cm | — |
| `L2`（j8 轴 → 笔尖） | **24.0 cm** | 17.714 + 6.286 | 笔长按实插 |

1.7 cm 的 `L1` 误差直接进 FK/IK：笛卡尔闭环会“自认为笔尖在线上”，
实际却偏 1~2 cm，足够画出界或顶到台面。

## 3. 角度口径

```text
e1  = j7 - 95          第一节仰角；j7=95 -> 第一节水平
rel = j8 - 180         小臂相对角；j8=180 -> 两节共线
e2  = e1 + rel = j7 + j8 - 275   第二节世界仰角

lx = L1*cos(e1) + L2*cos(e2)
lz = L1*sin(e1) + L2*sin(e2)
```

`(lx, lz)` 以 j7 轴心为原点，`lz=0` 就是 j7 轴高度，不是地面。
面板里的“距离”和“z 起/止”都是这个口径。

> 2026-10-29 更正：旧文把 `j7+j8≈275` 叫“共线”，其实那是 `e2≈0`
> （第二节水平）的读数关系。共线看 `j8≈180`；两组条件别混。

## 4. 代码里的落点

- `line_tool.py`：`L1`、`L2`、`J7_AXIS_X`、`J7_AXIS_Z` 是唯一来源，
  注释里明确标了 measured。
- `arm_simple_gui.py`：直接引用 `line_tool` 的常量，不再复制一份。
- `gazebo/transbot_arm_simple/urdf/arm_simple.urdf`：大臂长度已改成
  0.10 m，和实测一致；笔仍为 0.24 m（j8 轴到笔尖）。
- `tests/test_line_tool.py`：FK/IK、范围、接近路径都按实测长度回归。

## 5. 复测方法（换臂/换笔/重新安装后）

1. **T1**：量 j7 轴心到 base_link 前缘/底面的 x、z，填 `J7_AXIS_X/Z`。
2. **T2**：卷尺量 j7 轴心 → j8 轴心，填 `L1`。
3. **T3**：按实际 j9 夹笔角装好笔，量 j8 轴心 → 笔尖，填 `L2`。
4. 摆一个已知姿态，用 `python3 draw_line.py <dist>` 或面板「范围」核对；
   再用真机慢速靠近，确认笔尖和预测位置差在几毫米内。
5. 改完同步更新本文件、`line_tool.py`、`urdf/arm_simple.urdf`，
   不要只改其中一个。

## 6. 相关限制

- **关节限位（以最新 GUI `../console/transbot_gui.py` 为准）**：
  j7 0~225°、j8 15~240°、j9 60~180°（夹笔 158~160°）。
  这三组值同时用于 `line_tool.py`、Gazebo URDF 和 UDP agent；
  `arm_min` 旧文档里的 j8 30~270 是厂家手册口径，不再采用。
- 台面：j7 轴高 8.0 cm，规划留 `FLOOR_MARGIN=2.5 cm`，
  所以相对高度下限 `Z_FLOOR_REL=-5.5 cm`。
- 臂展：`REACH_MAX=L1+L2=34.0 cm`，规划留 `REACH_MARGIN=2.0 cm`，
  即最远按 32.0 cm 算，避免完全伸直的奇异点。
- 回差：约 1° ≈ 4 mm 笔尖误差；画线只许单向走，步长 ≤2°/包。
