# 在数据工作台中重新建图

打开 Transbot 语义建图工作台 → **数据阅读**，选中会话文件夹，点击顶部 **建图 / 重新建图**。进入文件夹后也可以点此按钮；选中某个分卷时，自动合并同一次录制的全部分卷。一个文件夹有多次录制时会先让你选择其中一组。

已有当前地图时会询问是否替换。取消询问不会启动任务；确认后重新建图，成功后直接更新当前地图。旧地图整体归入项目 archive/maps/，构建过程和日志集中在 archive/builds/；失败或取消不替换当前地图，原始 bag 不会修改。

建图窗口显示当前阶段、耗时和后台日志，可以取消。录制中不允许建图；建图中不能切换或重命名会话。窗口关闭前须等待建图结束或取消收尾，避免留下后台 ROS 进程。

此入口会用包里的雷达、里程计和底盘 TF 重新运行 SLAM，排除包里旧的 `/map`、AMCL 位姿和 `map→odom`，不会把已有静态底图直接导出冒充新建图。相机缺失或没有相机安装外参，不妨碍二维雷达建图；底盘到雷达的变换必须完整。

发生传感器或里程计 TF 时间回退、超过 1 秒的断档时，自动取最长的连续区间，并显示“仅使用连续片段 … 秒”。没有足够连续数据或缺少必要变换会报错，不跨异常时段强行拼接。

完成后重新打开分卷，阅读器会加载新地图和新轨迹。若新地图只覆盖部分时间，时间轴限制在该分卷与地图的交集并提示；完全不在有效时段内的分卷仍可看原始传感器和里程计视图，不借用旧 AMCL 坐标。

每组录制的当前地图固定放在 `maps/<录制名>/`，包含 `map.pgm`、`map.yaml`、`trajectory.bag` 和 `association.json`。阅读器只读取这里，不再自动选择散落旧图或归档图。移动整个会话时连同 maps/ 一起复制即可；不必携带归档才能查看当前结果。

English entry: **Data Workbench → Session Browser → Build / Rebuild Map**. Existing maps require confirmation; previous versions are retained. Reopen the split after completion to load the new map.
