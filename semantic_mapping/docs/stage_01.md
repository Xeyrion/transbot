# 第一阶段：离线语义建图演示

阶段整理日期：2026-11-18。项目交付名：**Transbot Semantic Mapping Studio**。

## 已完成流程

机器人本地采集 RGB、深度、雷达、里程计、TF 与相机信息，经校验回传控制机。按会话管理数据，独立执行二维建图与语义生成，联合回放 RGB 检测和物品候选点，导出最终展示地图。

常用方案为 YOLO26s（中心深度基线）和 YOLO26s 分割（原 B1，掩膜表面深度）。共享权重，每次录制独立保存结果。采样图像、二维检测、深度拒绝原因、三维观测、候选物品与所用地图快照可追溯。

```text
RGB → 类别、检测框/掩膜
     + 配对深度、相机内参 → 相机系三维表面点
     + 相机外参、采集时刻机器人位姿 → map/odom 物品观测
     → 多帧融合 → 物品候选点集 → 可选栅格底图展示
```

## 完成边界

阶段完成表示工具链与离线演示已贯通。候选数不等于真实物品数，深度接受率不等于位置准确率。COCO 模型用于通用物品演示，裂缝模型尚未训练。外参精度、里程计漂移、实例关联和深度空洞需要后续定量研究。

下一阶段先固定数据，分别评价检测、深度定位与融合，再开展裂缝分割标注、训练和地图表达研究。
