# 当前项目状态

更新：2026-11-18（用户侧）。正式名称：**Transbot 语义建图工作台 / Transbot Semantic Mapping Studio**。源码目录为 `transbot/semantic_mapping/`。

第一阶段交付范围是可演示的离线语义建图流程。范围、证据和后续研究见[阶段总结](stage_01.md)。

## 当前能力

- 中英文工作台统一进入录制和数据阅读；录制名称点击开始时生效，已有会话在阅读器主窗口重命名。
- 录前时间与驱动准备、录制锁、优雅收尾和逐文件校验回传已接入 GUI。实时健康与控制状态存入内存盘，结束后归档。
- 从包内数据重新建图，新图成功后生效，旧地图集中归档。
- YOLO26s 与 YOLO26s 分割为常用方案，分别记录检测、深度投影与融合，保留二维拒绝结果。
- 推理框、掩膜、对齐深度、地图候选编号及关联高亮可同时回放，地图可放大、缩放和导出。
- 语义结果按录制管理，模型共享；生成显示动态进度条、阶段和已用时间。
- 源码与数据解耦：本机配置引用现有数据位置，整理不搬动 bag、标注图片、权重或已有输出。
